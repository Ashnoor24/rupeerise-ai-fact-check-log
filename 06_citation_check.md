# Perplexity Citation Check

## Prompt Used
> What were India's monthly UPI transaction volume and value in the most recent month, and how much did they grow compared with the same month last year? Cite official sources.

## Perplexity Output
- **Date:** 23 November 2026

In October 2026, India's Unified Payments Interface (UPI) reached a new all-time high, processing **25.47 billion transactions** with a total value of **₹31.53 lakh crore**—crossing the ₹31 lakh crore mark for the first time. Compared to October 2025, transaction volume grew by **23% year-on-year**, while transaction value increased by **16% year-on-year**. The average daily transaction value also crossed ₹1 lakh crore for the first time, driven by festive shopping and everyday digital payments.
